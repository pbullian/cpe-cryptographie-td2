Installation par l'implant du bras

  1. Retroussez votre manche gauche : le port NX-7 se trouve sur la face interne de l'avant-bras.
  2. Téléchargez le firmware, sa signature et la clé publique, et rangez-les ensemble dans un dossier de work/.
  3. Branchez le câble NeuroJack : lancez le firmware dans la toolbox, jamais directement sur votre poste :
    docker compose -f docker-compose.student.yml run --rm toolbox sh /work/<dossier>/neurolien-v2.1.sh
  4. Gardez le bras immobile pendant la remontée du nerf médian. Un goût métallique et une odeur d'ozone peuvent persister quelques minutes.

Pour une latence minimale, le transfert passe par notre constellation. Évitez les orages solaires.
